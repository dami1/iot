Estrutura básica e documentação

p5.js é uma biblioteca JavaScript criada por Lauren McCarthy em 2014 como reinterpretação do Processing para a web. A premissa é a mesma: tornar a programação acessível para artistas, designers e pessoas sem formação técnica, com foco em output visual e interativo direto no navegador.

Ao contrário do Pure Data, onde o programa é um grafo de objetos conectados, em p5.js o programa é um texto — uma sequência de instruções em JavaScript que o navegador interpreta e executa. Os mesmos conceitos de objeto, método e atributo da aula 1 aparecem aqui de forma explícita no código.

Estrutura fundamental
setup() e draw()

Todo sketch p5.js tem a mesma estrutura obrigatória — idêntica ao Arduino em conceito. setup() roda uma vez ao iniciar: configura o canvas, define tamanho, inicializa variáveis. draw() roda em loop contínuo — por padrão 60 vezes por segundo — redesenhando a cena a cada frame.

Esse loop é o equivalente ao loop() do Arduino e ao patch em execução do PD. É onde o sistema lê entradas e atualiza saídas em tempo real.

Primeiro sketch

sketch.js · estrutura básica
function setup() {
  createCanvas(800, 600); // cria o canvas em pixels
  background(240); // fundo cinza claro (0=preto, 255=branco)
}

function draw() {
  background(240); // redesenha fundo a cada frame (apaga rastro)
  fill(200, 77, 10); // cor laranja em RGB
  noStroke(); // sem borda
  circle(mouseX, mouseY, 60); // círculo na posição do mouse
}

Funções e variáveis fundamentais

createCanvas(w, h)
Cria a área de desenho em pixels. Chamado uma vez no setup().
background(r, g, b)
Preenche o fundo com cor. No draw(), apaga o frame anterior.
fill(r, g, b)
Define a cor de preenchimento das formas seguintes.
stroke(r, g, b)
Define a cor da borda. noStroke() remove a borda.
circle(x, y, d)
Desenha um círculo no ponto x,y com diâmetro d.
rect(x, y, w, h)
Retângulo com canto superior esquerdo em x,y.
line(x1, y1, x2, y2)
Linha entre dois pontos.
text(str, x, y)
Renderiza texto no canvas. textSize() define o tamanho.
map(val, a1, a2, b1, b2)
Fundamental: remapeia val do intervalo [a1,a2] para [b1,b2]. Equivalente ao mapeamento que fazemos no PD.
mouseX / mouseY
Variáveis globais com a posição atual do cursor no canvas.
width / height
Dimensões do canvas. Útil para posicionar elementos relativamente.
frameCount
Número de frames executados desde o início. Serve como relógio para animações e eventos temporais.

Documentação

A referência oficial do p5.js é uma das documentações mais bem estruturadas do ecossistema criativo. Cada função tem descrição, parâmetros, tipo de retorno e exemplos interativos rodando diretamente na página.

  • p5js.org/reference — referência completa de todas as funções, organizadas por categoria: shape, color, input, transform, math, sound…
  • editor.p5js.org — editor online com preview em tempo real. Não requer instalação — funciona diretamente no navegador. Ideal para o laboratório.
  • p5js.org/examples — galeria de exemplos com código aberto. Ponto de partida para qualquer técnica: partículas, noise, geometria, input.
  • openprocessing.org — comunidade de sketches públicos em p5.js e Processing. Código-fonte aberto para explorar e adaptar.
Atividade: abrir o editor online em editor.p5js.org e reproduzir o sketch acima. Alterar os valores de cor, tamanho e posição. Retirar o background() do draw() e observar o rastro que se forma — o fundo não apagado acumula os frames anteriores.

Sensores do computador — mouse, teclado e microfone

Assim como no Pure Data, o p5.js acessa as entradas nativas do computador antes de qualquer hardware externo. Mouse, teclado e microfone estão disponíveis como variáveis globais e funções de evento — sem bibliotecas adicionais.

Mouse

mouseX / mouseY
Posição atual do cursor dentro do canvas, atualizada a cada frame.
pmouseX / pmouseY
Posição do cursor no frame anterior. A diferença com mouseX/Y indica velocidade e direção do movimento.
mouseIsPressed
Booleano: true enquanto qualquer botão do mouse estiver pressionado.
mousePressed()
Função de evento — chamada automaticamente no clique. Definir fora de draw() para tratar eventos discretos.

Teclado

keyIsPressed
Booleano: true enquanto qualquer tecla estiver pressionada.
key
Caractere da última tecla pressionada. Ex: 'a', ' ', 'Enter'.
keyCode
Código numérico. Constantes disponíveis: UP_ARROW, DOWN_ARROW, SPACE, ENTER…
keyPressed()
Evento disparado ao pressionar uma tecla. Usar para lógica discreta em vez de polling no draw().

Microfone — p5.sound

A biblioteca p5.sound (incluída por padrão no editor online) oferece acesso ao microfone e análise de áudio em tempo real.

p5.AudioIn
Objeto que representa a entrada de áudio do sistema — microfone ou linha. Requer permissão do usuário no navegador.
.getLevel()
Retorna a amplitude atual do sinal de 0 a 1. Equivalente ao [env~] do PD.
p5.FFT
Análise espectral em tempo real. .analyze() retorna array de 1024 valores de amplitude por frequência.
sketch.js · amplitude do microfone controlando o tamanho de um círculo
let mic;

function setup() {
  createCanvas(800, 600);
  mic = new p5.AudioIn();
  mic.start(); // solicita permissão ao navegador
}

function draw() {
  background(248, 247, 244);
  let vol = mic.getLevel(); // 0 a 1
  let diam = map(vol, 0, 1, 20, 400);
  fill(200, 77, 10);
  noStroke();
  circle(width / 2, height / 2, diam);
}
Atividade: combinar os três sensores em um único sketch — mouse controla posição, teclado muda a cor, microfone controla o tamanho. Usar map() para normalizar todos os valores para a faixa de cada parâmetro visual.

Câmera como sensor

A câmera transforma o p5.js em um sistema de visão — em vez de posição do mouse, o input é luz, movimento e forma capturados em tempo real. O objeto p5.Element criado por createCapture() devolve o feed de vídeo como dado manipulável.

createCapture(VIDEO)
Acessa a câmera do dispositivo. Retorna um elemento de vídeo que pode ser desenhado no canvas ou passado para análise.
image(vid, x, y, w, h)
Desenha o frame atual do vídeo no canvas. Atualiza automaticamente a cada draw().
vid.loadPixels()
Carrega os pixels do frame atual em um array RGBA acessível via vid.pixels[].
vid.pixels[]
Array com os valores R, G, B, A de cada pixel — 4 valores por pixel, em sequência linear.
sketch.js · câmera espelhada no canvas
let cam;

function setup() {
  createCanvas(640, 480);
  cam = createCapture(VIDEO);
  cam.size(640, 480);
  cam.hide(); // esconde o elemento HTML nativo
}

function draw() {
  translate(width, 0);
  scale(-1, 1); // espelha horizontalmente
  image(cam, 0, 0);
}

Detecção de movimento por diferença de pixels

A técnica mais simples de visão computacional sem biblioteca: comparar o frame atual com o anterior pixel a pixel. Onde a diferença for grande, há movimento.

sketch.js · detecção de movimento por diff de pixels
let cam, prevPixels;

function setup() {
  createCanvas(640, 480);
  cam = createCapture(VIDEO);
  cam.size(640, 480);
  cam.hide();
}

function draw() {
  cam.loadPixels();
  let movimento = 0;
  if (prevPixels) {
    for (let i = 0; i < cam.pixels.length; i += 4) {
      let diff = abs(cam.pixels[i] - prevPixels[i]);
      movimento += diff;
    }
  }
  prevPixels = cam.pixels.slice();
  let nivel = map(movimento, 0, 5000000, 0, 255);
  background(nivel, 77, 10); // mais laranja = mais movimento
}

Bibliotecas de reconhecimento — face, mãos e esqueleto

Modelos de visão computacional treinados em milhões de imagens rodam hoje diretamente no navegador via TensorFlow.js. As bibliotecas abaixo encapsulam esses modelos em APIs simples — em poucas linhas é possível obter as coordenadas de 468 pontos do rosto, 21 pontos de cada mão ou 33 pontos do corpo.

MediaPipe
google.github.io/mediapipe
docs ↗
Framework do Google para pipelines de percepção em tempo real. Roda no navegador via WASM ou WebGL. Modelos de alta precisão com latência baixa. Base para as soluções de face, mão e pose descritas abaixo.
Face Landmarker — 478 pontos Hand Landmarker — 21 pontos / mão Pose Landmarker — 33 pontos do corpo Object Detection
ml5.js
ml5js.org
docs ↗
Biblioteca de machine learning amigável, construída sobre TensorFlow.js e projetada para uso com p5.js. Encapsula os modelos do MediaPipe e outros em uma API consistente — ml5.faceMesh(), ml5.handPose(), ml5.bodyPose() — com callbacks simples e integração direta ao canvas p5.
faceMesh handPose bodyPose imageClassifier soundClassifier neuralNetwork
face-api.js
justadudewhohacks.github.io/face-api.js
GitHub ↗
Biblioteca especializada em detecção e reconhecimento facial. Além dos landmarks, oferece detecção de expressão facial (feliz, triste, surpreso…) e reconhecimento de identidade por embedding. Útil para instalações que reagem a emoções.
68 pontos faciais detecção de expressão reconhecimento de identidade

Como integrar ao p5.js

A forma mais direta é via CDN — incluindo o script no index.html antes do sketch. No editor online do p5.js, as bibliotecas são adicionadas em Sketch → Add Library ou via tag script no index.html da aba de arquivos.

index.html · carregando ml5.js via CDN
<script src="https://cdnjs.cloudflare.com/ajax/libs/p5.js/1.9.0/p5.min.js"></script>
<script src="https://unpkg.com/ml5@1/dist/ml5.min.js"></script>
<script src="sketch.js"></script>

Integração em sketch — ml5.js handPose

Um sketch completo que usa a câmera como sensor de gestos: ml5.js detecta a posição das mãos em tempo real e os dados dos 21 pontos de cada mão controlam elementos visuais no canvas.

sketch.js · handPose — posição dos dedos controlando círculos
let cam, handPose, maos = [];

function preload() {
  // carrega o modelo antes do setup()
  handPose = ml5.handPose({ flipped: true });
}

function setup() {
  createCanvas(640, 480);
  cam = createCapture(VIDEO);
  cam.size(640, 480);
  cam.hide();
  // inicia a detecção e guarda resultados em maos[]
  handPose.detectStart(cam, (resultado) => { maos = resultado; });
}

function draw() {
  image(cam, 0, 0);
  
  for (let mao of maos) {
    for (let ponto of mao.keypoints) {
      fill(200, 77, 10);
      noStroke();
      circle(ponto.x, ponto.y, 10);
    }
  }
}

Estrutura dos dados retornados

  • O array maos[] contém um objeto por mão detectada — normalmente até 2.
  • Cada objeto tem keypoints[] — array de 21 objetos com propriedades x, y, z e name (ex: index_finger_tip, thumb_tip…).
  • As coordenadas x e y já estão no espaço do canvas — prontas para usar em circle(), line() ou qualquer função de desenho.
  • O parâmetro flipped: true espelha horizontalmente — essencial para que o movimento da mão corresponda ao que o usuário vê.
Atividade: usar as coordenadas da ponta do dedo indicador (name === 'index_finger_tip') para controlar a frequência de um oscilador via Web Audio API — ou exportar os dados via OSC para um patch Pure Data usando a biblioteca p5.serialport. O gesto vira interface audiovisual.

Variação — bodyPose

sketch.js · bodyPose — esqueleto completo
let cam, bodyPose, corpos = [], conexoes;

function preload() {
  bodyPose = ml5.bodyPose("BlazePose");
}

function setup() {
  createCanvas(640, 480);
  cam = createCapture(VIDEO);
  cam.size(640, 480); cam.hide();
  bodyPose.detectStart(cam, (r) => { corpos = r; });
  conexoes = bodyPose.getSkeleton(); // pares de pontos conectados
}

function draw() {
  image(cam, 0, 0);
  for (let corpo of corpos) {
    // desenha as conexões do esqueleto
    for (let [a, b] of conexoes) {
      stroke(200, 77, 10); strokeWeight(2);
      line(a.x, a.y, b.x, b.y);
    }
    // desenha os pontos
    for (let p of corpo.keypoints) {
      fill(255); noStroke();
      circle(p.x, p.y, 8);
    }
  }
}
